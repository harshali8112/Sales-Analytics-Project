 📊 Sales Analytics Project (Excel + PostgreSQL + Power BI)
 📌 Overview
This project demonstrates an end-to-end data analytics workflow including data cleaning in Excel, SQL analysis, and interactive dashboard creation using Power BI.

 🛠 Tools Used
- Microsoft Excel (Data Cleaning)
- SQL (Data Analysis & Queries)
- Power BI (Dashboard Visualization)

📂 Project Workflow
 1. Data Cleaning (Excel)
- Removed duplicates
- Handled missing values
- Standardized formats

 2. SQL Analysis
- Used joins, group by, and aggregate functions
- Extracted insights like total sales, profit, and region-wise performance

3. Power BI Dashboard
- Created KPI cards (Sales, Profit, Orders, Profit Margin)
- Monthly sales trend analysis
- Category and region-wise breakdown
- Top customer analysis
- Dynamic filters using slicers

 📊 Key Insights
- Identified top-performing customers
- Analyzed monthly sales trends
- Found highest revenue-generating category
- Region-wise performance comparison

 🚀 Outcome
This project demonstrates strong skills in:
- Data Cleaning
- SQL Querying
- Data Visualization
- Business Insight Generation
